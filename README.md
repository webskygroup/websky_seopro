# Websky SEO Pro

Professional SEO utilities for OpenCart 4.0.2.x:

- Dynamic XML sitemap at `/sitemap.xml`
- Product JSON-LD structured data
- Admin enable/disable setting
- Automatic startup and sitemap route registration

## Installation

1. Download `websky_seo.ocmod.zip` from the GitHub release.
2. Upload it from **Extensions > Installer**.
3. Open **Extensions > Extensions > Modules**.
4. Install and enable **Websky Professional SEO**.

The package code remains `websky_seo` for compatibility with the live deployment at mosallaseatash.ir.

## Compatibility

- OpenCart 4.0.2.x
- PHP 8.1+
